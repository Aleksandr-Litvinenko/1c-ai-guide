# AI-assisted разработка в 1С

Для code review и генерации BSL рабочие бизнес-данные обычно не нужны. Начинайте с исходников.

## Минимальная связка

```text
выгрузка XML/EDT
  → Agent Skills / правила проекта
  → контекстный MCP или индекс
  → BSL-анализатор
  → тесты
  → review разработчиком
```

## Что дать агенту

- структуру репозитория;
- правила именования и стандарты разработки;
- релевантные модули и метаданные;
- команду сборки;
- команду статической проверки;
- тесты и ожидаемый результат;
- список файлов, которые менять нельзя.

## Хорошие первые задачи

- объяснить существующий механизм;
- найти места использования реквизита;
- написать unit-тест;
- добавить проверку заполнения;
- подготовить безопасный рефакторинг одного модуля;
- обновить документацию по фактическому коду.

## Definition of done

- изменения минимальны и относятся к задаче;
- BSL-проверки проходят;
- тесты проходят;
- выгрузка собирается обратно;
- нет секретов и персональных данных;
- diff просмотрен человеком;
- поведение описано в документации или тесте.
