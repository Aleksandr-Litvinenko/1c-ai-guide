# Roadmap

- [x] Сценарии выбора стека.

- [x] Машиночитаемый каталог.

## 0.2 — Проверяемость

- [x] Сверка репозиториев и ссылок через GitHub API.
- [x] Поля совместимости: ОС, runtime, транспорт и режим доступа к данным.
- [x] Зафиксированный commit SHA, дата последнего push и архивный статус.
- [x] Уровень проверки и ссылки на доказательства для каждого инструмента.
- [x] Автопроверка внутренних ссылок и рискованных формулировок.
- [x] Еженедельный недеструктивный аудит метаданных.

## 0.3 — Практика

- [x] Три инструкции из реальных интеграций: OData 1С:Фреш, задачи Bitrix24 и лиды из backend-формы.
- [x] Безопасные по умолчанию CLI-примеры и unit-тесты без секретов.
- [ ] Минимальный безопасный demo-стенд на тестовых данных.
- [ ] Воспроизводимый read-only аудит через OData с серверным запретом записи.
- [ ] Пример code review BSL без доступа к базе.
- [ ] Шаблон threat model для AI-интеграции с 1С.
- [ ] End-to-end проверки на Windows и Linux с зафиксированными версиями 1С/EDT.

## 1.0 — Community guide

- [ ] Минимум 20 инструментов с воспроизводимыми инструкциями.
- [ ] Проверки ключевых сценариев на Windows и Linux.
- [x] Английские версии главной страницы и трёх инструкций по подключению.
- [ ] Английские версии остальных инструкций, SECURITY и VERIFICATION.
- [ ] Ежемесячный changelog экосистемы AI × 1C.

Предложения принимаются через issues и pull requests. Приоритет получают задачи с воспроизводимым примером, понятной пользой и явно описанным уровнем доступа.
